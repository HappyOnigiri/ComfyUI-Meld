# Meld Image Loader (MeldImageLoader)

A node that loads an image and automatically extracts embedded generation metadata (prompts, model, sampler settings, etc.).
It also attempts to load the checkpoint model used based on the metadata.

## Overview

When you load an image generated by ComfyUI (or A1111, etc.) by dragging and dropping it, this node performs the following processing in addition to simply loading the image data:

1.  **Metadata Parsing**: Parses embedded Workflow JSON, Prompt JSON, or A1111 format text information.
2.  **Parameter Extraction**: Extracts generation parameters such as Seed, Steps, CFG, Sampler, Scheduler, and Resolution.
3.  **Automatic Model Loading**: Attempts to load the model (MODEL, CLIP, VAE) based on the checkpoint name recorded in the metadata.
4.  **Prompt Extraction**: Outputs positive/negative prompts as strings.

This significantly streamlines the process of reusing previously generated images or fine-tuning based on their parameters.

## Inputs

### Required

| Name | Type | Description |
| :--- | :--- | :--- |
| **image** | `COMBO` | Select the image file to load. You can also upload by dragging and dropping the image onto the node. |

## Outputs

| Name | Type | Description |
| :--- | :--- | :--- |
| **IMAGE** | `IMAGE` | The loaded image data (Tensor). |
| **MODEL** | `MODEL` | The model detected and loaded from metadata. None if not found. |
| **CLIP** | `CLIP` | The CLIP detected and loaded from metadata. None if not found. |
| **VAE** | `VAE` | The VAE detected and loaded from metadata. None if not found. |
| **positive** | `STRING` | The extracted positive prompt. |
| **negative** | `STRING` | The extracted negative prompt. |
| **summary** | `STRING` | A summary text of all extracted parameters (including logs). Can be viewed with a Show Text node. |
| **base_settings** | `BASE_SETTINGS` | A dictionary data grouping basic settings such as Seed, Steps, CFG, Sampler name, etc. Can be extracted into individual values using [Meld Settings Unpacker](./MeldSettingsUnpacker.md) etc. |

## Usage & Tips

*   **Parameter Extraction Priority**:
    Metadata is parsed with the following priority:
    1.  **ComfyUI Workflow JSON**: Contains the most detailed information.
    2.  **ComfyUI Prompt JSON**: Used if generated via API, etc.
    3.  **A1111 Info Text**: For images generated with Automatic1111 WebUI.
    4.  **Default**: Default values are used if nothing is found.

*   **About Model Loading**:
    The model is loaded if the model name (checkpoint name) described in the metadata exists under `models/checkpoints` in the current ComfyUI environment. Even if the filename does not match exactly, it may try to find and load a similar name, but success is not guaranteed.

*   **Using base_settings**:
    The output `base_settings` can be connected to the [Meld Settings Unpacker](./MeldSettingsUnpacker.md) node to be extracted as individual INT/FLOAT/STRING values such as `seed`, `steps`, `cfg`.
