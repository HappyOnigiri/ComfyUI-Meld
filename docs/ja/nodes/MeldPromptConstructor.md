# Meld Prompt Constructor (MeldPromptConstructor)

指定されたディレクトリ内のテキストファイルを再帰的に検索し、各ファイルから行を抽出してプロンプトを構築するノードです。
動的な構文（ランダム選択）や、否定プロンプトの自動分離機能を備えています。

## 接続イメージ

`Meld Prompt Constructor` -> `CLIP Text Encode`

## 入力 (Inputs)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **directory** | STRING | `./my_prompts` | プロンプトファイル（.txt）が格納されているディレクトリのパス。 |
| **file_pattern** | STRING | `*.txt` | 読み込むファイルのパターン（glob形式）。例: `*.txt`, `character_*.txt` |
| **seed** | INT | 0 | ランダム選択や順次選択の開始位置を決定するシード値。 |
| **selection_method** | COMBO | `random` | 行の選択方法。<br>- `random`: ランダムに1行選択。<br>- `sequential`: シード値に基づいて順次選択。 |
| **use_break** | BOOLEAN | `True` | ファイルごとの結合時に `BREAK` キーワードを使用するかどうか。`False`の場合はカンマで結合されます。 |

## 出力 (Outputs)

| 名前 | 型 | 説明 |
| :--- | :--- | :--- |
| **positive_prompt** | STRING | 生成されたポジティブプロンプト。 |
| **negative_prompt** | STRING | 自動抽出されたネガティブプロンプト。 |

## 機能詳細と使い方のヒント

### 1. ファイルの読み込みと選択
指定ディレクトリ（サブディレクトリ含む）内の `file_pattern` に一致する全ファイルを読み込みます。
ファイル名の先頭が `_` (アンダースコア) で始まるファイルは無視されます。
各ファイルから、有効な行（空行やコメントのみの行を除く）が1行選択されます。

### 2. コメント機能
ファイル内で以下の記法を使うと、その部分は無視されます。
- `// コメント` (行末まで)
- `# コメント` (行末まで)
- `/* コメント */` (ブロックコメント)

### 3. 動的構文 (Dynamic Syntax)
中括弧 `{}` を使うことで、ランダムな選択が可能です。
- **単純な選択**: `{A|B|C}` → A, B, C のいずれか1つが選ばれます。
- **重み付け選択**: `{0.1::レア|0.9::コモン}` → 確率を指定して選択できます（数値::テキスト）。重みが指定されていない項目は 1.0 として扱われます。

### 4. ネガティブプロンプトの自動分離
プロンプト内にハイフン `-` で始まる要素を含めると、それは**ネガティブプロンプト**として出力されます。
- **単一要素**: `-low quality` → ネガティブプロンプトに `low quality` が追加され、ポジティブからは削除されます。
- **グループ**: `-(worst quality, bad anatomy)` → 括弧内の要素すべてがネガティブプロンプトに移動します。

### 5. BREAKの使用
`use_break` が `True` の場合、異なるファイルから読み込んだプロンプトの間に ` BREAK ` が挿入されます。これにより、各ファイルの内容が互いに混ざり合わず、独立したブロックとしてCLIPに認識されやすくなります。
