# Meld Save Image (MeldSaveImage)

生成された画像を保存し、同時に Image Manager のデータベースへ自動登録する高機能な保存ノードです。

プロンプト、ワークフロー、モデル情報などのメタデータを抽出して保存するほか、画像の視覚的ハッシュ (pHash) を用いて「親画像（元画像）」を自動的に推定し、系統樹（Lineage）を構築します。

## 入力 (Inputs)

### 必須 (Required)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **images** | `IMAGE` | - | 保存する画像データ (`[Batch, H, W, C]`)。 |
| **filename_prefix** | `STRING` | `%date:yyyy-MM-dd-HH-mm-ss%` | 保存ファイル名の接頭辞。日付フォーマット (`%date:yyyy-MM-dd%` など) が使用可能です。 |
| **extension** | `COMBO` | `png` | 保存フォーマット (`png`, `webp`) を選択します。 |
| **quality** | `INT` | `90` | 画像の保存品質 (1-100)。主に `webp` 形式で使用されます。 |

### オプション (Optional)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **origin_image** | `IMAGE` | - | img2img の元画像などを明示的に「親画像」として指定する場合に入力します。指定された画像の pHash を計算し、データベース内の最も近い画像を親としてリンクします。 |
| **positive** | `STRING` | - | ポジティブプロンプト。通常は [Meld Image Loader](./MeldImageLoader.md) や [Meld Prompt Constructor](./MeldPromptConstructor.md) から接続しますが、手動入力も可能です。メタデータとして保存されます。 |
| **negative** | `STRING` | - | ネガティブプロンプト。メタデータとして保存されます。 |
| **tags** | `STRING` | - | 画像に付与するタグ。カンマ区切りで複数のタグを指定できます（例: `girl, masterpiece, best quality`）。 |

## 出力 (Outputs)

| 名前 | 型 | 説明 |
| :--- | :--- | :--- |
| **images** | `IMAGE` | 保存された画像をそのまま出力します。プレビュー用または後続の処理に使用できます。 |

## 機能詳細

### 1. 自動データベース登録
画像を保存すると同時に、以下の情報をローカルの SQLite データベースに記録します。
*   ファイルパス、生成日時
*   画像解像度、ファイルサイズ
*   pHash, SHA256 ハッシュ値
*   プロンプト (Positive/Negative)
*   使用モデル (Checkpoint)
*   ワークフロー (Workflow JSON)

### 2. 親画像の自動推定 (Lineage)
img2img や アップスケールを行った際、元の画像と生成画像の「親子関係」を自動的に記録します。
*   **自動モード**: `origin_image` が未接続の場合、生成画像の視覚的特徴 (pHash) に基づいて、直近に生成された画像の中から類似度の高いものを親として推定します。
*   **手動モード**: `origin_image` に画像を接続すると、その画像を明示的に親として検索・リンクします。

### 3. タグの継承
設定により、親画像に付与されていたタグを子画像へ自動的に引き継ぐことができます。これにより、img2img の試行錯誤中でもタグ付けの手間を削減できます。
