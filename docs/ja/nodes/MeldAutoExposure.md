# Meld Auto Exposure (MeldAutoExposure)

画像の明るさ（輝度）を分析し、目標とする明るさに近づくように自動的にガンマ補正を行うノードです。
暗すぎる生成画像を明るく補正したり、逆に明るすぎる画像を落ち着かせたりする場合に便利です。

**接続イメージ:**
`KSampler` -> `VAE Decode` -> **[Meld Auto Exposure]** -> `Save Image`

## 入力 (Input)

### 必須 (Required)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **image** | `IMAGE` | - | 補正対象の画像。バッチ（複数枚）入力にも対応しており、各画像ごとに個別に解析・補正されます。 |
| **correction_strength** | `FLOAT` | `0.5` | **補正の強さ** (0.0 - 5.0)。<br>値が大きいほど、目標の明るさに近づける力が強くなります。<br>`0.0` にすると補正は行われません（ガンマ値 1.0）。基本的には `0.5` 前後で調整し、効果が薄い場合は値を上げてください。 |
| **target_brightness** | `FLOAT` | `0.5` | **目標とする明るさ** (0.1 - 0.9)。<br>`0.5` が中間の明るさです。<br>より明るくしたい場合は値を上げ（例: 0.7）、暗くしたい場合は下げてください（例: 0.3）。 |

### オプション (Optional)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **gamma_limit_min** | `FLOAT` | `0.2` | ガンマ値の下限リミッター。極端に暗く補正されすぎるのを防ぎます。 |
| **gamma_limit_max** | `FLOAT` | `2.5` | ガンマ値の上限リミッター。極端に白飛びするような補正を防ぎます。 |

## 出力 (Output)

| 名前 | 型 | 説明 |
| :--- | :--- | :--- |
| **image** | `IMAGE` | 明るさが補正された画像。 |
| **calculated_gamma** | `FLOAT` | 実際に適用されたガンマ値（計算値）。<br>バッチ処理の場合は平均値が出力されます。 |
| **current_brightness** | `FLOAT` | 元画像の平均輝度。<br>バッチ処理の場合は平均値が出力されます。 |

## 仕組みとヒント

- **自動調整のロジック**:
  画像の平均輝度（Rec.601準拠）を計算し、`target_brightness` との差分に応じてガンマ値を算出します。
  - 元画像が目標より**暗い**場合 → 画像を明るく補正
  - 元画像が目標より**明るい**場合 → 画像を暗く補正

- **調整のコツ**:
  - まずは `target_brightness` を好みの明るさに設定します。
  - 補正が強すぎて画質が劣化する場合（コントラストがきつすぎるなど）は、`correction_strength` を下げてみてください。
  - 逆に補正が足りない場合は `correction_strength` を上げるか、リミッター (`gamma_limit_min/max`) の範囲を広げてみてください。
