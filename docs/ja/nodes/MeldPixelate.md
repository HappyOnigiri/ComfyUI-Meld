# Meld Instant Pixelate (MeldPixelate)

画像をダウンサンプリングしてから元のサイズに拡大し、モザイク処理（ピクセル化）を行うノードです。
指定したピクセルサイズのブロックで画像を再構成し、レトロなドット絵風の効果を出したり、プライバシー保護のためのモザイクとして使用したりできます。

**接続イメージ:**
`Load Image` -> **[Meld Instant Pixelate]** -> `Save Image`

## 入力 (Input)

### 必須 (Required)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **image** | `IMAGE` | - | 処理対象の画像。バッチ入力（[B, H, W, C]）に対応しています。 |
| **pixel_size** | `INT` | `16` | **ピクセルブロックのサイズ** (1 - 256)。<br>値が大きいほど、モザイクの目が粗くなります（ブロックが大きくなります）。<br>例えば `16` の場合、元の画像の 16x16 ピクセルの領域が 1つの大きなドットになります。 |

### オプション (Optional)

なし

## 出力 (Output)

| 名前 | 型 | 説明 |
| :--- | :--- | :--- |
| **image** | `IMAGE` | ピクセル化処理が適用された画像。元の画像と同じ解像度で出力されます。 |

## 仕組みとヒント

- **高品質なドット化 (Area Downscaling)**:
  縮小処理に `area` 補間（平均画素法）を使用しています。
  これは、各ブロック内の色の平均値計算してドットの色を決定するため、単純な間引き（間引いて縮小）に比べて、元の画像の色味や特徴をよく保ったきれいなドット絵が生成されます。

- **くっきりとしたエッジ (Nearest Upscaling)**:
  拡大処理に `nearest` 補間（最近傍法）を使用しています。
  補完による「ぼやけ」を発生させず、ドットの角が立ったシャープな見た目を維持したまま元の解像度に戻します。

- **使用例**:
  - **ドット絵風アート**: `pixel_size` を 4〜16 程度に設定すると、レトロゲームのようなドット絵調になります。
  - **プライバシー保護**: `pixel_size` を大きめ（32以上など）に設定して顔などの特定部分を隠すモザイクとして利用できます（Mask処理と組み合わせると効果的です）。
