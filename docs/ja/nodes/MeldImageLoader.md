# Meld Image Loader (MeldImageLoader)

画像を読み込み、その画像に埋め込まれている生成メタデータ（プロンプト、モデル、サンプラー設定など）を自動的に抽出するノードです。
また、メタデータに基づいて使用されたチェックポイントモデルのロードも試みます。

## 概要

ComfyUIで生成された画像（またはA1111などで生成された画像）をドラッグ＆ドロップなどで読み込むと、単に画像データとしてロードするだけでなく、以下の処理を同時に行います。

1.  **メタデータの解析**: 埋め込まれたWorkflow JSON、Prompt JSON、またはA1111形式のテキスト情報を解析します。
2.  **パラメータの抽出**: Seed, Steps, CFG, Sampler, Scheduler, 解像度などの生成パラメータを抽出します。
3.  **モデルの自動ロード**: メタデータに記録されているチェックポイント名を元に、モデル（MODEL, CLIP, VAE）をロードしようとします。
4.  **プロンプトの抽出**: 正/負のプロンプトを文字列として出力します。

これにより、過去に生成した画像を再利用したり、パラメータを参照して微調整したりする作業が大幅に効率化されます。

## 入力 (Inputs)

### Required

| 名前 | タイプ | 説明 |
| :--- | :--- | :--- |
| **image** | `COMBO` | 読み込む画像ファイルを選択します。画像をノードにドラッグ＆ドロップすることでアップロードも可能です。 |

## 出力 (Outputs)

| 名前 | タイプ | 説明 |
| :--- | :--- | :--- |
| **IMAGE** | `IMAGE` | ロードされた画像データ（Tensor）。 |
| **MODEL** | `MODEL` | メタデータから検出・ロードされたモデル。見つからない場合はNone。 |
| **CLIP** | `CLIP` | メタデータから検出・ロードされたCLIP。見つからない場合はNone。 |
| **VAE** | `VAE` | メタデータから検出・ロードされたVAE。見つからない場合はNone。 |
| **positive** | `STRING` | 抽出されたポジティブプロンプト。 |
| **negative** | `STRING` | 抽出されたネガティブプロンプト。 |
| **summary** | `STRING` | 抽出された全パラメータの概要テキスト（ログ含む）。Show Textノードなどで確認できます。 |
| **base_settings** | `BASE_SETTINGS` | Seed, Steps, CFG, Sampler名などの基本設定をまとめた辞書データ。`Meld Settings Unpacker` などで個別の値に取り出せます。 |

## 使い方とヒント

*   **パラメータ抽出の優先順位**:
    メタデータは以下の順序で優先して解析されます。
    1.  **ComfyUI Workflow JSON**: 最も詳細な情報が含まれます。
    2.  **ComfyUI Prompt JSON**: API経由などで生成された場合。
    3.  **A1111 Info Text**: Automatic1111 WebUIで生成された画像の場合。
    4.  **Default**: 何も見つからない場合はデフォルト値が使用されます。

*   **モデルのロードについて**:
    メタデータに記載されているモデル名（チェックポイント名）が、現在のComfyUI環境の `models/checkpoints` 以下に存在する場合にロードされます。ファイル名が完全一致しない場合でも、類似の名前を探してロードを試みる場合がありますが、必ずしも成功するとは限りません。

*   **base_settingsの活用**:
    出力される `base_settings` は、`Meld Settings Unpacker` ノードに接続することで、`seed`, `steps`, `cfg` などの個別のINT/FLOAT/STRING値として取り出すことができます。
