# Meld Infinite Heart Generator (MeldPatternHeart)

画像上にハートのパターンを自動的に描画・配置するノードです。
グリッド状に敷き詰めたり、マスクの境界線（エッジ）に沿って配置したりと、多彩な装飾が可能です。背景素材の作成や、特定のオブジェクトの周りをハートで囲むといった演出に利用できます。

**接続イメージ:**
`Image` -> **[Meld Infinite Heart Generator]** -> `Save Image`

## 入力 (Input)

### 必須 (Required)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **image** | `IMAGE` | - | ベースとなる画像。この画像の上にハートが描画されます。 |
| **size** | `INT` | `64` | **ハートのサイズ** (px)。<br>描画されるハートの大きさを指定します (8 - 1024)。 |
| **opacity** | `FLOAT` | `1.0` | **不透明度** (0.0 - 1.0)。<br>`1.0` で完全に不透明、数値を下げると透けたハートになります。 |
| **padding** | `INT` | `0` | **間隔の調整**。<br>ハート同士の隙間を調整します。正の値で広がり、負の値で重なり合います。<br>基本のグリッド間隔は `size + padding` で計算されます。 |
| **random_rotation** | `BOOLEAN` | `False` | **ランダム回転**。<br>`True` にすると、各ハートがランダムな角度で描画されます。 |
| **placement** | `COMBO` | `Inside` | **配置モード**。<br>ハートをどのように配置するかを決定します（詳細は「配置モードについて」を参照）。<br>- `Inside`: 領域内に収まるように配置<br>- `Overlap`: 領域に少しかかれば配置<br>- `Edge`: 境界線上に配置<br>- `Edge Inward`: 境界線上で内側を向くように配置 |

### オプション (Optional)

| 名前 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| **mask** | `MASK` | - | **配置領域マスク**。<br>ハートを配置するエリアを限定するために使用します。指定しない場合は画像全体が対象となります。 |

## 出力 (Output)

| 名前 | 型 | 説明 |
| :--- | :--- | :--- |
| **IMAGE** | `IMAGE` | ハートパターンが描画された画像。 |

## 仕組みとヒント

- **配置モード (Placement) について**:
  - **Inside**: グリッド状に配置し、ハート全体がマスク領域（白）の中に完全に収まる場合のみ描画します。
  - **Overlap**: グリッド状に配置し、ハートの一部でもマスク領域（白）にかかっていれば描画します。
  - **Edge**: マスクの輪郭（境界線）を検出し、そのライン上にハートを並べます。
  - **Edge Inward**: `Edge` と同様に境界線上に並べますが、ハートの向きを「外側から内側」へ向くように自動回転させます。キャラクターをハートで囲む際などに効果的です。

- **調整のコツ**:
  - **密度の変更**: ハートをぎっしり詰めたい場合は `padding` を `0` や負の値に設定し、まばらにしたい場合は正の値を大きくします。
  - **エッジ装飾**: `mask` を入力し `placement` を `Edge` または `Edge Inward` にすることで、マスクされた被写体の周囲をハートでデコレーションできます。
